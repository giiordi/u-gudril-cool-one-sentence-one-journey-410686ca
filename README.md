## The sentence

> The night the river took their village, old Tomas lashed his door to a driftwood raft, rode the black water past the drowned church bell still tolling beneath the surface, and when the current finally set him down on a far mudbank at sunrise, he planted the door in the silt and called it home.

Why it is built this way, against the judge's brief:

- **A complete journey in one sentence** — a beginning (the river takes the village), a middle (the raft ride past the drowned bell), an arrival (the far mudbank at sunrise).
- **A turn** — the door starts as wreckage lashed to a raft and ends as the foundation of a new home; a place is reached and a person is remade in the same object.
- **Concrete detail, not abstract feeling** — a driftwood raft, a church bell still tolling under black water, silt underfoot.
- **A closing clause that lands** — "he planted the door in the silt and called it home" ends the journey with weight, somewhere the reader did not expect to be.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3, stdlib only) validates the sentence — 1 to 300 characters, exactly one sentence — and writes it to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).
